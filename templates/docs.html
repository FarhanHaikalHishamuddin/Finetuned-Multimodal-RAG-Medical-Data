API Reference

Integrate the MedRAG clinical intelligence engine directly into your hospital management system or mobile application.

Authentication

All API requests must include the X-API-KEY header. You can generate this key from your user dashboard after upgrading to a Premium account.

X-API-KEY: MED-YOUR_SECRET_TOKEN_HERE

Analyze Medical Case

Analyze clinical text and optional medical imagery using the fine-tuned Qwen-VL model.

POST /api/v1/analyze

Request Body (JSON)

FieldTypeDescription
textStringClinical findings or patient symptoms (Required).
imageStringBase64 encoded image string (Optional).

Example Python Request

import requests

url = "http://{{ request.host }}/api/v1/analyze"
headers = { "X-API-KEY": "MED-XXXXX" }
payload = {
    "text": "Chest X-ray shows opacity in the left lower lobe.",
    "image": None
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

Response Object

The server returns a structured JSON object including the AI's reasoning and similarity metrics.

{
    "status": "success",
    "results": {
        "generated_answer": "Community-Acquired Pneumonia",
        "generated_reasoning": "Based on the localized opacity...",
        "metrics": {
            "cosine": 0.89,
            "bert_f1": 0.92
        }
    }
}

Error Codes

CodeDescription
401Unauthorized: Missing or invalid API Key.
400Bad Request: Missing 'text' field.
500Internal Server Error: AI model inference failed.
